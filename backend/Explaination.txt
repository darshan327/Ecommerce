  => npm i cors dotenv express jsonwebtoken multer nodemon razorpay stripe validator cloudinary bcrypt

     Express.js → Backend server framework
     cors → Allows frontend and backend to communicate
     dotenv → Stores environment variables like API keys
     jsonwebtoken → JWT authentication/login tokens
     multer → File/image upload handling
     nodemon → Automatically restarts server during development
     Razorpay SDK → Indian payment integration
     Stripe SDK → International payment integration
     validator → Email/password validation
     Cloudinary SDK → Cloud image storage
     bcrypt → Password hashing

      =>🤫 Cloudinary
            This file is used to connect your backend project with Cloudinary.

              Cloudinary is used to:
              
              upload images
              store images online
              get image URLs
              manage media files
              
              In an eCommerce project, it is VERY useful because products need images.

              Frontend uploads image
                      ↓
              Backend receives image
                      ↓
              Cloudinary stores image in cloud
                      ↓
              Returns image URL
                      ↓
              Save URL in MongoDB

          Using:

           multer → gets image from frontend
           Cloudinary → uploads image online

         Difference Between Product Model and User Model
         Feature	    Product Model	       User Model
         Purpose	        Stores products	           Stores users
         Collection	        products	           users
         Main Data	        Product info	           Login/account info
         Contains	        price, images, sizes       email, password, cart
         Used In	        Product page	           Authentication
         Important Field	price	                   email
         Special Option	        bestSeller	           unique email
         Array Usage	        images, sizes	           cart object
